# Landing Page - Fagundes Decorações

# Sobre o projeto

Esta é uma landing page moderna e totalmente responsiva desenvolvida para a **Fagundes Decorações**.

O projeto foi construído utilizando **Angular**, com o objetivo de criar uma Single Page Application (SPA) performática e com uma experiência de usuário extremamente fluida. O design foi pensado para ser visualmente impactante e profissional, refletindo a alta qualidade e a excelência dos materiais e serviços para obras e reformas oferecidos pela empresa (Forros em gesso, Divisórias, Pisos, Projetos Acústicos, etc).

Para criar uma interface sofisticada e premium, foram utilizadas técnicas avançadas de frontend, como vídeos embutidos com fundo transparente (Alpha Channel / WebM), efeitos de *glassmorphism* nos componentes, e animações de alta performance baseadas em rolagem (scroll) utilizando a biblioteca **GSAP (ScrollTrigger)**. A paleta de cores escura e sofisticada, com fortes destaques na cor laranja e vermelho, reforça com propriedade a identidade visual da marca.

No desenvolvimento deste projeto, foram aplicados conceitos fundamentais e modernos do ecossistema Angular (Standalone Components), como:

*   **Componentização**: Criação de componentes reutilizáveis e modulares (Navbar, Hero, Serviços, Metodologia, Avaliações, Parceiros, Footer) para um código mais limpo e organizado.
*   **Animações Avançadas**: Integração nativa com o ecossistema GSAP para gerar revelações, transições de layout e efeitos de rolagem interativos e dinâmicos sem perda de performance.
*   **Estilização Encapsulada**: Cada componente possui seu próprio estilo (SCSS), evitando conflitos de classes e garantindo a manutenibilidade do código.
*   **Responsividade**: Implementação de layout flexível com Media Queries, Flexbox e CSS Grid para garantir uma experiência de navegação impecável em desktops, tablets e celulares, respeitando a ergonomia do usuário em cada tela.
